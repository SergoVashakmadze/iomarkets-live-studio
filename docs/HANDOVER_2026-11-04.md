## How judges test it without our credits (README, "Run it on your own keys")

1. No key: `uv sync && uv run pytest`. 158 offline tests replay recorded Meta responses.
2. Their own `META_API_KEY` in `.env`, then `uv run studio serve`: the full studio on their laptop,
   Teresa still (no lip movement), MMS voice. Without a key the page says to add one; it does not 500.
3. Their own Modal account, with lip-sync: `modal token new`, `bash deploy/lipsync_setup.sh`,
   `bash deploy/deploy.sh their.env 10`. Needs nothing from `iomarkets.tv-newsroom` or a local
   MuseTalk install (face-parse weights: pinned, SHA-256-checked Hugging Face copy).

**Lip-sync needs an NVIDIA GPU or a Modal account.** The README says so in a callout.

## If a judge asks for a hosted link

It would run on **our** Meta credit and Modal bill, so it is the operator's decision. To bring it back
with the same link and token: check no one else is using it, then
`uv run --no-project --with modal==1.6.1 modal deploy deploy/modal_app.py`. The Teresa pictures are now
tracked, so the refusal in `deploy/modal_app.py` can no longer fire from a clean checkout. Set the daily cap
first (`STUDIO_DAILY_BUDGET_USD` in the secret, `STUDIO_GPU_DAILY_BUDGET_USD` for the L40S). Stop it
again with `modal app stop iomarkets-live-studio`. Never `deploy.sh` for this: it rotates the token
and breaks the link already given out.
