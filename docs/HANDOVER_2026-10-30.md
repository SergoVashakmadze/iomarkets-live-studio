## What works now

- **The studio page** is a broadcast control room: logo, ON AIR tally, a two-box programme (the
  AI anchor and the guest side by side in the IoMarkets TV studio), name straps, ticker, and a
  programme recording that downloads as WebM at the end.
- **The anchor**, "Alexandra Morgan" (Teresa, a pre-existing HeyGen avatar), lip-synced with head
  and body movement by `lipsync/server.py` (MuseTalk v1.5 over her moving loop). Her voice is
  en-GB-LibbyNeural.
- **She speaks first**: a fixed greeting, voiced and lip-synced once and cached (`greeting.py`),
  plays the moment the interview starts; her opening question follows it.
- **Question variety**: a journalist's range of angles, one suggested per turn (`anchor.ANGLES`).
- **Cloud lip-sync**: the class `Lipsync` on a Modal **L40S** (1.1x real time once warm, ~46 s
  cold start with everything cached). It has no public URL; only token holders' page loads wake it.

## How to run it

Locally (workstation GPU):

```sh
uv run python scripts/anchor_assets.py            # once: the anchor's media, from the newsroom
cd ~/musetalk-local/MuseTalk && ~/musetalk-local/venv/bin/python \
  "../../Documents/d-drive/New Projects/iomarkets-live-studio/lipsync/server.py"   # :8766
uv run studio serve                                # http://127.0.0.1:8000
```

Deployed (Modal): `uv run --no-project --with modal==1.6.1 modal deploy deploy/modal_app.py`.
The private link with its token is in `~/.config/iomarkets-studio/judges-link.txt` (mode 600):
open it with `xdg-open "$(cat ~/.config/iomarkets-studio/judges-link.txt)"`, never paste it.
`bash deploy/warm.sh on 2` keeps the GPU up for two hours, then it switches itself off.
Costs and every guard against surprise bills: `docs/DEPLOY.md`.

   payoff for effort:

     (`live._short_start`), so the first clip renders in ~2 s.
   - **Streaming the clip** as it renders (fragmented MP4 or WebRTC) instead of waiting for
     the whole sentence: biggest gain, biggest change.
